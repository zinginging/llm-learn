## 3 源码与运行证据

- [factory.py:1239](https://github.com/langchain-ai/langchain/blob/d57f1ea32caa10005e816589c9a12c48f4889815/libs/langchain_v1/langchain/agents/factory.py#L1239) 构造 StateGraph；[factory.py:1909](https://github.com/langchain-ai/langchain/blob/d57f1ea32caa10005e816589c9a12c48f4889815/libs/langchain_v1/langchain/agents/factory.py#L1909) 将 checkpointer、store 等传给 graph.compile。由此不能将现代 LangChain 描述为无状态线性链框架。
- LangChain 离线实验实际读取 model-visible tool_call_schema，检查只有 month；身份由 runtime.context 注入。消息和工具结果由真实框架执行，但调用意图由脚本模型预定。
- LangGraph 离线实验用真实 SQLite saver，在先后独立进程中暂停与恢复，验证同意、拒绝、并行汇总和有界重试。不存在真实网络超时或模型决策。
- 完整输出、解释器与包版本见 [验证记录](../intermediate/验证记录.json)。没有调用付费模型、远端 MCP、业务数据库或 LangSmith 服务。

## 4 结论强度

API 与机制结论来自官方文档和指定源码，脚本行为来自发布包实跑。场景推荐、系统分层和评估清单是工程归纳。没有实测自然语言能力、跨供应商模型一致性、生产吞吐、故障事务语义或多租户安全。

不将检查点恢复描述为任意函数栈恢复，不将超时描述为外部操作必然取消，不将结构化输出描述为语义正确，也不将安装包自带 LangSmith 依赖解释为必须启用平台追踪。
