# Jev 校准评估与实验设计

本章把[总指南](../output/jev模型原理与实践学习指南.md)中的评估步骤展开为可执行的学习实验。需要先读[数学详解](01_概率与决策数学详解.md)。以下实验设计是建议，例子均为合成数据，不代表 Jev 效果。

## 1 分清准确性 排序能力与校准

准确性回答标签是否正确，排序能力回答正例能否排在负例之前，校准回答概率是否符合频率。三者不同。

一个模型给所有样本预测正例概率 0.1，若真实正例率也是 10%，可以在总体频率上校准，却不能区分任何样本。另一个模型把正例排得很高，但总把 70% 成立的事件说成 99%，则排序可能好而概率失准。

二元事件校准关注 E[Y | P=p]≈p。Choice 的 top-label calibration 则比较最大类别概率与所选类别正确率。不要把 Noul 的“正例发生率”和 Choice 的“选中类别正确率”混进同一张没有说明的图。

## 2 标签与数据切分

先写标签规则，再收集数据。对于“是否明确请求退款”，区分已退款、否认退款、咨询政策、请求退款和缺失上下文。标签应针对文本所述事实，不凭想象补充客观交易状态。

建议将小型学习集分为：

| 集合 | 用途 | 允许调整的内容 |
| --- | --- | --- |
| 开发集 | 修改问题、候选和标注规则 | 提示与 schema |
| 校准集 | 拟合概率映射、选择动作阈值 | 校准器与阈值 |
| 测试集 | 最终独立报告 | 不再调参 |

如果数据很少，可用交叉验证估计，但所有拟合、阈值选择和指标计算必须明确对应折。相同订单、客户、模板或近重复样本应分组切分。时间外推任务优先用较新的时间段作为测试集。

双人标注部分数据，保存分歧与裁决规则。原始分歧是任务本身不清楚的信号，不应一律认定模型错。

## 3 指标与手算

对 Noul 记录 TP、FP、TN、FN，再算 precision=TP/(TP+FP)、recall=TP/(TP+FN)。极不平衡任务尤其要看正例指标：99% 都是负例时，永远说“否”也有 99% accuracy。

概率指标使用未阈值化的输出：

```text
Brier = mean((p−y)^2)
LogLoss = −mean(y log p + (1−y) log(1−p))
```

教学样本概率 [0.8,0.8,0.2,0.2]，标签 [1,0,0,0]：Brier=(0.04+0.64+0.04+0.04)/4=0.19，log loss≈0.5697。0.8 组实际正例率为 0.5，0.2 组实际正例率为 0。四条样本太少，只能用来演算。

当预测为 0 但标签为 1 时，理论 log loss 无限大。数值实现可裁剪概率以避免 log(0)，但要记录 epsilon 与极端错误数量，不要用裁剪掩盖错误。

## 4 可靠性图与 ECE

把预测概率分箱，在每箱画横轴平均概率、纵轴正例比例，并注明样本量。Choice top-label 图应把纵轴换成分类正确率。

```text
ECE = Σ (箱内样本数/N) × |箱内平均概率−箱内实际频率|
```

上例按 0.2、0.8 两组分箱，ECE=0.5×0.2+0.5×0.3=0.25。若把所有样本放在一箱，平均概率 0.5、正例比例 0.25，也得到 0.25；一般数据中分箱变化会显著改变 ECE，不能依赖这个巧合。

分别检查中文、英文、稀有类、长上下文和模糊输入。总体平均校准好，某个部门或语言仍可能失准。可靠性图的频率估计应有不确定性范围；小样本分箱波动大。

校准基础可读 [Guo 等人的论文](https://proceedings.mlr.press/v70/guo17a.html)。这是概率评估背景，不是 Jev RLCD 算法说明。

## 5 校准后处理与阈值调优

Platt scaling 用标签拟合概率映射，isotonic regression 拟合单调映射。若只能获取概率，可对裁剪后的 logit(p) 拟合，明确这是输出后处理，并非获得了模型内部 logits。

后处理的参数只能在校准集拟合，测试集检查泛化。等距回归在小数据上可能过拟合；单调映射不保证修复模型排序，也无法弥补缺失候选或语义理解错误。

阈值调优只改变从概率到标签的规则；校准改变概率数值。调阈值使 F1 提高，并不能证明输出概率已校准。还需注意业务基础发生率变化会使旧映射失效。

## 6 自动处理覆盖率与成本

coverage=自动处理数量/总数量；selective risk=自动处理子集的错误数量/自动处理数量。空自动处理子集的 risk 应记为不可计算，而不是 0。

逐个阈值报告覆盖率、自动处理错误率、人工数量与正例召回。提高阈值通常减少自动处理，但不保证误判率严格下降；要观察曲线。

总成本估算包括模型调用、重试、人工复核和误判损失。比较候选模型时固定目标，例如“自动子集 precision 达到同一目标后，哪个覆盖率更高”，不要比较一个全自动系统与一个几乎全部转人工的系统。

## 7 学习实验步骤与结果表

1. 写 30 条合成边界样例，仅检查 schema 和问题含义。
2. 收集独立标注的真实样例，按上述规则切分；数量取决于罕见类与精度目标。
3. 若有 API 账户，固定模型与 SDK 版本，保存脱敏响应、延迟、usage 和实际模型 ID。
4. 跑规则、专用模型和结构化 LLM 基线，使用相同上下文。
5. 评估原始概率、校准映射、阈值和整体工作流。
6. 对顺序、等价改写、否定句、无关材料与注入文本做成对扰动。
7. 输出指标及失败案例，保留原始指标，禁止只公布最好看的切片。

结果表至少有模型版本、样本与正例数、macro-F1、正例 precision/recall、Brier、分箱说明、coverage、自动子集风险、p95 延迟、重试率和费用。没有实测的单元格写“未执行”，不要填假设结果。

## 8 两篇 Jev 研究怎么读

[多任务评估预印本](https://arxiv.org/abs/2609.37647)用于学习公共基准、固定模板与阈值影响；[事故文本预印本](https://arxiv.org/abs/2609.24052)用于理解人工标签、稀有变量和领域校准。两者的总体表现不能互相替代，因为任务、标签来源和概率事件不同。

阅读时分别记录：谁定义标签、是否使用人工真值、阈值在哪拟合、是否公开响应、哪个模型版本、哪些分布可能与训练重叠。写出三个结论：研究直接证明了什么、不能推出什么、自己的业务还需验证什么。
