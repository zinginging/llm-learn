# Jev 概率与决策数学详解

本章承接[总指南](../output/jev模型原理与实践学习指南.md)，解释从有限答案分布到业务动作的数学过程。需要了解加权平均和条件概率。所有数值均为自构造教学样例，不是 Jev API 输出。模型公式依据 2026-10-13 已核验的[官方 Confidence 文档](https://docs.typesafe.ai/confidence)，推导和应用分析为本章教学内容。

## 1 概率分布究竟描述什么

给定上下文 x、问题 q 和候选集合 C，模型返回可理解为 P(Y=c | x,q,C) 的估计。改变问题范围或候选集合，实际上改变了被评估的问题，因此不要期待原概率原封不动。

例如“哪个部门主办”是单选，“涉及哪些部门”是多标签。支付和技术都有涉及时，前者要定义主办规则，后者应拆成两个 Noul。一个类别概率很低，不等于记录中绝对没有该主题，它可能只是无法成为主类别。

分布满足每项介于 0 与 1，且总和约为 1。浮点运算和序列化可能导致轻微误差；接入代码应检查容差，明显不合法的响应不能静默归一化成可信结果。概率检查只能发现接口异常，无法验证语义。

## 2 Choice 的决策与 confidence

最常见选择是 argmax，即返回概率最大的类别。如果各类误判成本相同，且概率可作为真实条件概率使用，选 argmax 能最小化预期的单次分类错误。

但成本不同时应该比较各动作的期望损失：

```text
R(a | x) = Σ L(a,y) × P(y | x)
a* = argmin_a R(a | x)
```

L(a,y) 表示真实类别为 y 时采取动作 a 的损失。动作可以包括人工复核，不必与类别一一对应。例如对可能的资金异常，即使普通工单类别概率更高，也可能优先核验。

Choice confidence 将 p_max 从均匀分布基准 1/n 映射到 0 至 1：

```text
c = (p_max − 1/n) / (1 − 1/n)
p_max = 1/n + c × (1 − 1/n)
```

当 n=3 且 c=0.9 时，p_max≈0.9333；当 n=10 时，p_max=0.91。相同 confidence 不对应相同最大概率。候选数固定时，同时使用 c 和 p_max 相当于重复同一信息。

两个分布 [0.6,0.3,0.1] 与 [0.6,0.2,0.2] 的 c 都是 0.4，但领先第二名的差分别为 0.3 和 0.4。差值能描述竞争强度，却同样不是额外的正确性认证。

## 3 Score 的期望与隐含假设

Score 将等级看成随机变量 I，取值为 0 至 n−1：

```text
E[I] = Σ i × p_i
```

以三级量表为例，[0.2,0.5,0.3] 得到 1.1。若将输出映射成百分制，1.1/2×100=55，只改变单位，不增加精度，也不使量表成为客观测量。

期望使用了等距编号。轻微、中等、严重在实际业务里未必等距。例如严重事故的损失可能远高于中等事故，应该另定义损失向量 [1,5,100]。此时：

```text
期望业务损失 = 0.2×1 + 0.5×5 + 0.3×100 = 32.7
```

32.7 是假设损失单位下的期望，不是官方 score。只有业务损失量表有合理依据时，它才有决策价值。

均值也会掩盖分布形状。[0,1,0] 和 [0.5,0,0.5] 的均值都为 1，方差分别为 0 和 1。后者在最高等级上有 0.5 的概率，更值得检查。

## 4 Score confidence 的推导与并列

官方公式以最可能等级 m 为中心，计算平均绝对距离 D：

```text
D = Σ p_i × |i−m|
U = (1/n) × Σ |i−(n−1)/2|
c = max(0, 1−D/U)
```

U 是均匀分布相对中点的平均距离。n=2k 时 U=k/2；n=2k+1 时 U=k(k+1)/(2k+1)。例如三级量表 U=2/3，四级量表 U=1。n 必须至少为 2，否则分母没有意义。

注意 D 的中心是模态 m，而 U 的中心是量表中点，两者不是相同定义。不能把 c 解读成方差，也不能认为 c=0 只对应均匀分布：两端分裂等分布同样会被截断为 0。

对于 [0.4,0.4,0,0.2]，m=0 时 D=1、c=0；m=1 时 D=0.8、c=0.2。文档参考代码选择升序列表中的第一个最大值，即最小编号模态。复现时遵循这个规则；托管 API 边界仍未实测。

若 HTTP 概率键是字符串，用 int(key) 排序后计算。近似并列检测可以用容差，但应作为单独的业务标记，不偷偷改变参考公式。不要对多个模态取平均后代入 m；那是另一个统计量。

## 5 Noul 阈值与人工复核

设 p 为“是”的概率，误报成本为 C_FP，漏报成本为 C_FN：

```text
R(是) = (1−p)×C_FP
R(否) = p×C_FN
选择“是”的条件：p > C_FP/(C_FP+C_FN)
```

该推导假定正确动作成本为零，且没有其他后果。若误报成本 9、漏报成本 1，则阈值 0.9；若漏报成本 9、误报成本 1，则阈值 0.1。它解释了为什么统一使用 0.5 不合理。

加入每次成本固定为 0.3、结果完全正确的人工复核，并设两类错误成本均为 1：

```text
p < 0.3：选择“否”
0.3 < p < 0.7：人工复核
p > 0.7：选择“是”
边界：明确制定等损失时的优先规则
```

真实人工也会犯错，等待时间和漏处理存在成本，必须把这些代入 L。若概率未校准，公式给出的最优性也不成立。

## 6 练习与答案

1. 五分类最大概率 0.8，confidence 是多少？答案：(0.8−0.2)/0.8=0.75。
2. 四级 Score 分布 [0.1,0.2,0.3,0.4] 的期望是多少？答案：2.0；最高等级概率仅 0.4。
3. 上一分布的参考 confidence 是多少？m=3，D=1，U=1，因此为 0。
4. n=5 的均匀基准 U 是多少？答案：6/5=1.2。
5. 两个 Noul 都输出 0.9，是否意味着同时正确概率为 0.81？只有具有合适联合概率解释且事件独立时才能相乘；API 独立评估不提供这种假设。

完成标准：能从分布算出摘要、指出信息损失，并为具体动作写出成本矩阵。
