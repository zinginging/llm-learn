# Agent 上下文建设论文阅读笔记

核验日期：2026-10-14。先读原文的方法、评估协议与局限，再看社区解读。以下为自写摘要；没有复现论文实验。首发年份与正式发表状态分开记录，不推断未核实的会议接收。

## 1 RAG

- 标题：Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks。
- 作者：Patrick Lewis 等；arXiv 首发 2020 年。
- [原文](https://arxiv.org/html/2005.11401)、[元数据](https://arxiv.org/abs/2005.11401)。
- 问题与方法：把外部检索与生成模型结合，用非参数知识补充参数记忆。
- 实验阅读：关注知识密集型任务、检索器与生成器设置，而不只看最终分数。
- 对 Agent 的启示：外部知识可以在调用时提供；检索不到或检索错误会影响答案。
- 局限：原始架构不是长期 Agent 的记忆写入、时间更新或权限管理方案。

## 2 ReAct

- 标题：ReAct: Synergizing Reasoning and Acting in Language Models。
- 作者：Shunyu Yao 等；arXiv 首发 2022 年。
- [原文](https://arxiv.org/html/2210.03629)、[元数据](https://arxiv.org/abs/2210.03629)。
- 方法：让模型交替进行任务推理、行动与读取环境观察。
- 阅读重点：观察如何修正下一步，以及问答任务与交互任务的对照差异。
- 启示：上下文包含不断产生的工具反馈，必须随状态演变。
- 局限：显式轨迹不保证长期记忆正确；失败工具输出仍可能带来错误。

## 3 Lost in the Middle

- 标题：Lost in the Middle: How Language Models Use Long Contexts。
- 作者：Nelson F. Liu 等；2023-07-06 首发，TACL 正式卷期为 2024 年。
- [期刊入口与 PDF](https://aclanthology.org/2024.tacl-1.9/)、[arXiv](https://arxiv.org/abs/2307.03172)。
- 方法：改变多文档问答和键值检索中相关信息的位置与上下文长度。
- 结果含义：论文模型存在位置敏感性，窗口长度不等于可靠使用范围。
- 实验设计启示：同一证据放在前、中、后，控制其他内容，重复测量。
- 局限：不能把当时模型的结果视为当前模型固定曲线。

## 4 MemGPT

- 标题：MemGPT: Towards LLMs as Operating Systems。
- 作者：Charles Packer 等；2023-10-12 首发；阅读 v2，2024-02-12。
- [全文](https://arxiv.org/html/2310.08560v2)。
- 方法：借鉴分层内存，在有限上下文与外部储存间移动信息，管理控制流。
- 评估范围：文档分析与多会话对话。
- 启示：把存储容量、当前可见信息和读取策略分开考虑。
- 局限：读写与调度有成本，外部存储不意味着模型始终看到全部内容。

## 5 LLMLingua

- 标题：LLMLingua: Compressing Prompts for Accelerated Inference of Large Language Models。
- 作者：Huiqiang Jiang 等；arXiv 首发 2023 年。
- [原文](https://arxiv.org/html/2310.05736)、[作者项目](https://github.com/microsoft/LLMLingua)。
- 方法：预算控制与细粒度 token 压缩，保留对目标推理有用的信息。
- 阅读重点：具体任务和压缩比下的质量与成本，而不是宣传中的最大压缩倍率。
- 启示：上下文预算可优化，但必须测量信息损失。
- 局限：压缩后的表示不一定适合作为长期可审计的事实记忆。

## 6 LongMemEval

- 标题：LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory。
- 作者：Di Wu 等；2024-10-14 首发；作者仓库标注 ICLR 2025。
- [全文 v2](https://arxiv.org/html/2410.10813v2)、[项目](https://github.com/xiaowu0162/LongMemEval)。
- 方法：500 个问题覆盖提取、多会话、时间、知识更新与拒答；把记忆处理拆成索引、检索、读取。
- 启示：评估不能只测单条事实回忆，应包含更新和无答案情形。
- 局限：回答问题与完成环境动作是不同能力。

## 7 A-MEM

- 标题：A-MEM: Agentic Memory for LLM Agents。
- 作者：Wujiang Xu、Zujie Liang、Kai Mei、Hang Gao、Juntao Tan、Yongfeng Zhang。
- 2025-02-17 首发；arXiv 页面标注 NeurIPS 2025；阅读 v11。
- [原文](https://arxiv.org/html/2502.12110v11)。
- 方法：结构化记忆笔记、动态索引、连接和记忆演化。
- 启示：写入时组织信息与后续检索同样重要。
- 局限：关系与摘要由模型产生时可能出错；应区分原始记录和衍生笔记。
- 复现入口：系统组件仓库与实验仓库不同，见项目核验记录。

## 8 上下文工程综述

- 标题：A Survey of Context Engineering for Large Language Models。
- 作者：Lingrui Mei 等；2025-07-17 首发。
- [原文](https://arxiv.org/html/2507.13334)、[元数据](https://arxiv.org/abs/2507.13334)。
- 内容：围绕检索与生成、上下文处理、上下文管理，以及 RAG、记忆、工具和多 Agent 系统组织领域。
- 学习用途：用作术语地图和追溯文献的入口。
- 局限：分类体系不是经过统一实验认证的最佳部署架构。

## 9 ACE

- 标题：Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models。
- 作者：Qizheng Zhang、Changran Hu 等；2025-10-06 首发；本笔记按 v1 方法与表格阅读。
- [全文](https://arxiv.org/html/2510.04618v1)、[项目](https://github.com/ace-agent/ace)。
- 方法：生成、反思、整理分工；局部 delta 更新、去重与经验条目维护，减少整体重写导致的细节丢失。
- 评估：AppWorld 与金融相关任务，区分离线和在线反馈设置。
- 表 1 的 42.4 与 59.4 为四项指标均值，差值是 17.0 个百分点，不能当通用业务提升率。
- 启示：维护原子经验条目和反馈记录；不直接把一次推理总结升格成事实。
- 局限：反思质量与反馈可信性重要，新增调用也需要计入预算。

## 10 LongMemEval-V2

- 标题：LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues。
- 作者：Di Wu、Zixiang Ji、Asmi Kawatkar、Bryan Kwan、Jia-Chen Gu、Nanyun Peng、Kai-Wei Chang。
- arXiv 首发 2026 年；本次按预印本 v1 阅读。
- [原文](https://arxiv.org/html/2605.12493v1)、[官方项目](https://github.com/xiaowu0162/LongMemEval-V2)。
- 方法：451 问题覆盖静态状态、动态状态、流程、环境陷阱与前提意识；记忆系统从环境轨迹收集证据供问答。
- 基线：AgentRunbook-R 使用 RAG 知识池，AgentRunbook-C 使用轨迹文件与 coding agent 搜集证据。
- 启示：从“记住用户说过什么”扩展到“学到如何在环境里工作”。
- 局限：问答协议不能替代真实操作成功率；应额外验证动作和状态恢复。

## 阅读顺序与共同问题

入门先读综述与 ReAct，再看 RAG、Lost in the Middle、MemGPT；随后读 A-MEM、LLMLingua、ACE；最后用两代 LongMemEval 设计评估。

每篇都回答：它改了模型权重还是输入？记忆保存在哪里？何时写入与读取？如何处理矛盾和失效？评估是在找证据、答问题还是完成任务？对照是否控制模型与调用预算？
