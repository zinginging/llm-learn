# 来源与版本核验

核验日期：2026-10-26。RSI 按 Recursive Self-Improvement 解读，范围是 AI/Agent 的自我改进，与金融 RSI 指标无关。采用 A 类原论文、会议、作者仓库和官方博客；聚合站与搜索结果只用于发现候选，不承担关键机制或数值的最终证据。

## 1 研究与读取范围

实际下载并通过 pdftotext 提取 STOP、SICA、DGM、SEAL、AlphaEvolve、AIDE²、RRSI、PAST-Bench、AI4AI-Bench 共 9 篇 arXiv PDF，阅读方法、实验及关键边界；另外读取 ACL Gödel Agent PDF。Self-Refine 与 Reflexion 本轮主要用于原始摘要和方法定位，未在本文重新做全文实验分析。

[论文快照](../intermediate/论文快照.json) 记录上述 9 篇的题名、作者、首次 citation date、读取版本、固定链接与 PDF SHA-256。下载时使用 arXiv 返回的 PDF URL，版本由对应摘要页与正文核对；复读应使用记录中的 pinned_pdf_url，并比对哈希，不能假设不带版本的链接永远不变。

搜索覆盖经典反馈、自改代码、权重适应、2026 年 Agent/R&D 改进与评测，属于选题式深度调研，不宣称穷尽所有 RSI 论文。没有调用模型或执行上游自修改程序。

## 3 官方博客与证据冲突

- [Sakana DGM 博客](https://sakana.ai/dgm/) 发布于 2025-05-30，辅助解释开放式 Agent 归档；实验设置优先使用本次 v3 PDF。
- [Google DeepMind AlphaEvolve 博客](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/) 发布于 2025-05-14，早于论文；不从博客推定完整服务开源。
- [Weco AIDE² 博客](https://www.weco.ai/blog/first-evidence-of-recursive-self-improvement) 页面标注 2026-07-14，后更新链接至 9 月论文。其 reward hacking 63%→34% 与论文摘要 55%→32% 不同，不能混用；本报告以论文为技术基准，保留冲突说明。
- “first evidence”“full RSI”等标题或作者主张不作为领域共识。AIDE² 的论文 §3.6 明确 ignition 结论不确定，应与主结果一同呈现。

## 5 数值核验与不可比较项

| 常见数字 | 正确解释 | 不应写成 |
| --- | --- | --- |
| SICA 17%→53% | 固定随机 SWE-bench Verified 50 题子集，作者特定设置 | 全量 SWE-bench 成绩或通用提升 |
| SICA 约 7000 美元 | 一次 15 轮原始 API 运行的历史费用 | 当前模型价格或复制预算保证 |
| DGM 20.0%→50.0% | Verified 分阶段评价，强候选最多扩展到 200 题 | 完整 500 题统一测试 |
| DGM 14.2%→30.7% | 完整 Polyglot 的额外比较 | 与演化 50 题子集 14%→38% 混写 |
| SEAL 33.5%→47.0% | passage-only 与 SEAL 单 passage 知识适应；冻结 base 为 32.7% | GPT-4.1 本身问答分数或全 ARC 结果 |
| AIDE² 7 次改进 | 8 天、初始加 99 个提案中的接受改写 | 99 次成功改进或 ignition 已证明 |
| AI4AI-Bench 0.250 | 原算法=0.1 的归一化研究分数 | 25% 准确率 |
| 本地审计 1.0 | 4 个手工教学样本全部匹配 | 真实模型性能或统计保证 |

RRSI 的最大增幅随 split、policy 和度量变化。本报告不从摘要最大值合成平均收益，也不将 tokens 缩减直接写为相同幅度的端到端费用降低。
