## 内容与目录

主题目录使用 `YYYYMM_主题名`，跨月继续学习时复用已有主题。

```text
YYYYMM_主题名/
├── README.md      # 导航与运行说明
├── output/        # 成熟学习指南与总结
├── docs/          # 论文、推导、来源和实践模板
├── scripts/       # 实验与示例程序
├── input/         # 必要输入与资料清单
├── intermediate/  # 可追溯中间结果
└── tmp/           # 临时产物
```

只创建实际需要的目录。根目录保留项目入口与协作协议，主题正文在各自目录内维护。详细约定见 [AGENTS.md](AGENTS.md)。

## 来源与验证

- **A 类**：论文、会议或期刊官网、作者代码、数据卡片、官方技术文档，用于核实核心事实。
- **B 类**：论文聚合与技术社区，用于发现候选并追溯 A 类来源。
- **C 类**：中文解读与论坛，用于理解语境，核心事实仍需原始来源。

动态信息注明核验日期；数据、代码和模型许可分别核对。教学示例、实验计划与实测结果明确区分。仓库当前主要是学习文档，未完成真实模型基准或业务系统验收；各主题来源记录说明具体范围。

## 离线示例

Jev 概率公式演算仅使用 Python 标准库，不需要网络、密钥或模型权重。在仓库根目录执行：

```bash
python 202610_jev模型学习/scripts/confidence_examples.py
```

输出展示相同 Score 对应不同分布，以及并列最可能等级对 confidence 的影响。它验证数学例子，不验证模型能力。

## 持续学习

新增主题先明确问题与范围，再整理来源、写学习文档和必要的验证。更新已有结论时保留版本、来源与适用条件，并检查主题及根目录导航链接。密钥、敏感业务数据、大型权重和缓存不纳入提交。
