## 能力归类

DataHub的UI ingestion与Source工作单元主要采集元数据；OpenMetadata的Service/API资产和REST OpenAPI解析主要登记接口结构。二者不能直接等同任意业务服务的运行时代理。Semantica注册表是代码级扩展点，GraphRAG统一documents输入，Ontop提供支持范围内的关系数据映射；完整来源管理和场景编排仍需明确建设。

## 许可修正

OpenMetadata固定SHA根LICENSE为Apache-2.0；ingestion/LICENSE为Collate Community License 1.0，REST source文件头引用该许可。Excluded Purpose限制竞争性SaaS/PaaS/IaaS等在线服务，不能把整套采集代码概括为Apache-2.0。具体目标版本和文件范围应分别核对；本次没有追溯所有历史发行包。

此边界与Ontology Studio编写界面属于Collate的决定分别记录。公开源码、商业界面和宽松许可不是同一件事。
