# 运行与复核

重建日期2026-11-17。以下仅标准库离线示例，不需GPU、密钥、模型或外部服务；首次重新获取上游文件需要网络。

```bash
python scripts/contract_demo.py
python scripts/source_management_demo.py
python scripts/source_audit.py
```

前两个是自建教学代码，不运行五框架。第一个校验净回款、fan-out、时区/授权和版本；第二个校验三种来源结构及等价通道选择。实际结果在intermediate。

source_audit读取忽略的tmp/sources并核对清单版本与散列，同时对Python源码作AST解析，不能证明上游运行行为。新工作区可执行`python scripts/fetch_sources.py`复取固定SHA的文件；脚本保留TLS和环境代理，不执行下载代码。

Ontop输入含TTL、OBDA和SPARQL，未运行真实引擎。需要自行在测试库建立对应表、选择支持的JDBC与发行版，连接文件放tmp，再按[官方CLI](https://ontop-vkg.org/guide/cli)测试。查询中的tenant条件不是权限边界，源端/网关仍需落实授权。

未运行五套服务、SSO/RLS、真实数据源、LLM/embedding或性能基准。管理UI为需求设计，不能把JSON或Python原型当成已交付管理平台。
