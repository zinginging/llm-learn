## 3 核心系统论文

### Orca：迭代级调度

- 作者：Gyeong-In Yu、Joo Seong Jeong、Geon-Woo Kim、Soojeong Kim、Byung-Gon Chun。
- 来源：[OSDI 2022 正式页面](https://www.usenix.org/conference/osdi22/presentation/yu)。
- 关键机制：以单次生成迭代为调度粒度，完成请求可以退出、新请求可以加入；部分算子选择性 batching。
- 对比意义：在线推理也能够批处理，不必等整批所有序列结束才接新请求。
- 证据边界：本文核对会议摘要和机制定位，未复现原 GPT-3 175B/旧基线性能，也不搬用历史倍率作为现代系统保证。

### PagedAttention / vLLM：KV 管理影响吞吐

- 作者：Woosuk Kwon 等。
- 来源：[2309.06180v1](https://arxiv.org/abs/2309.06180v1)，2023-09-12，页面标注 SOSP 2023。
- 关键机制：分页式管理动态增长的 KV，减少碎片、预留和冗余复制，支持共享。
- 对比意义：能接纳的有效序列数受 KV 内存约束；单纯提高请求并发而不管理 KV 可能导致抢占/重算。
- 边界：主要讨论内存管理，不是 FlashAttention 同义词；论文的相对吞吐在其硬件/模型与基线下成立。

### FlashAttention：以 IO 为中心优化注意力

- 作者：Tri Dao、Daniel Y. Fu、Stefano Ermon、Atri Rudra、Christopher Ré。
- 来源：[2205.14135v2](https://arxiv.org/abs/2205.14135v2)，2022-05-27 首发、2022-06-23 v2。
- 关键机制：tiling 减少 HBM/SRAM 间读写的 exact attention；另有 block-sparse 扩展，应区分。
- 对比意义：优化底层计算对在线、离线都可能有帮助。
- 边界：摘要包含训练实验，不能直接外推成在线推理加速倍数；后续内核版本与硬件支持另核对。

### Speculative Decoding：减少串行目标模型步骤

- 作者：Yaniv Leviathan、Matan Kalman、Yossi Matias。
- 来源：[ICML 2023 / PMLR 202](https://proceedings.mlr.press/v202/leviathan23a.html)、[论文 PDF](https://proceedings.mlr.press/v202/leviathan23a/leviathan23a.pdf)。
- 方法：廉价近似模型提出多个 token，目标模型并行验证；精确采样方案保持目标分布。
- 对比意义：不是把 batch 开大，而是改变目标模型解码的执行组织。
- 边界：读取 PDF 的方法与假设；实际加速依赖接受率与验证/草稿开销，数学分布等价不是浮点执行逐字一致保证。未复现其 T5 实验。

### Sarathi-Serve：长 Prefill 与 Decode 的干扰

- 作者：Amey Agrawal 等。
- 来源：[2403.02310v3](https://arxiv.org/abs/2403.02310v3)、[PDF](https://arxiv.org/pdf/2403.02310v3)，2024-03-04 首发、2024-06-17 v3。
- 方法：chunked prefills 与 stall-free 调度，将长输入分块并尽量避免暂停 decode，兼顾吞吐和尾部生成延迟。
- 对比意义：大 batch 的收益可能被首 token/生成卡顿抵消，需要满足延迟要求下的容量指标。
- 边界：实际读取 PDF；特定 A100/模型/trace 的倍率不直接代表当前引擎，也不是所有负载的最优参数。

### DistServe：Prefill/Decode 分离与 Goodput

- 作者：Yinmin Zhong 等。
- 来源：[2401.09670](https://arxiv.org/abs/2401.09670)、[PDF](https://arxiv.org/pdf/2401.09670)，2024 年工作；本轮网页 PDF 链接不带版本，不宣称固定修订号。
- 方法：分离两阶段 GPU，分别优化资源和并行，并按带宽放置以控制 KV 传输。
- 对比意义：目标是同时满足 TTFT/TPOT 的最大可服务速率，而不只是无限排队时的峰值 tokens/s。
- 边界：实际读取 PDF；分离增加状态移动与部署开销，不能视为免费提速。本文未复现其 GPU 容量实验。
