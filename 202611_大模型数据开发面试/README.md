## 无密钥实验

在本主题目录运行，Python 3.10+、标准库即可，无网络、GPU、模型或付费API：

```bash
python scripts/interview_exercises.py
python scripts/validate_materials.py
```

[实验脚本](scripts/interview_exercises.py)验证SQL并列/空值、JOIN膨胀、ROWS/RANGE、CDC重放与墓碑、MinHash/LSH算术、数据配比、masked loss、DPO手算和检索指标。结果在[离线演算](intermediate/离线演算结果.json)。它们不是模型成绩或集群性能。

[校验脚本](scripts/validate_materials.py)检查题库冻结哈希、问题/答案覆盖、链接、JSON与Python语法。若保留本地资料快照，还核对来源文件哈希；未保留tmp时如实报告跳过原始资料哈希。
